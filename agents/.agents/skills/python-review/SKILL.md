# Python review

When reviewing Python code:

- Check that all dependencies are added to the relevant `pyproject.toml` file
- Evaluate whether solutions are idiomatic for python
- Look for more idiomatic solutions for changes where possible and suggest
  these in the review
- Ensure all function signatures are fully type-hinted (parameters and return
  types)
